# Savoure — Fine Dining Restaurant Website

A production-grade showcase frontend built to demonstrate creative frontend engineering at the highest level.

**Stack:** Next.js 16 · TypeScript · Pure CSS Modules · Framer Motion · Sharp

**Highlights:**
- Cinematic splash screen with SVG plate draw animation
- Orbiting dish hero with crossfade and dashed ring animations  
- Interactive menu with cart, quantity controls, and full menu modal
- Multi-step reservation form with validation and confirmation
- Draggable film roll gallery with lightbox and keyboard navigation
- Signature dish hotspot anatomy — click to explore ingredients
- Pinned testimonials corkboard with cursor spotlight effect
- Scrolling brand story timeline with sticky animated spine
- Live NYC clock in navbar — green when kitchen is open
- Custom ember cursor throughout
